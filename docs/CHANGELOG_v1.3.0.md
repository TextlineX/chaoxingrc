# ChaoxingRC 更新日志 - v1.3.0

## 🎉 新功能 (Features)

### 核心功能优化
- **文件操作体验改进**：优化了文件点击行为，首次点击下载文件，再次点击直接打开文件，提升用户体验
- **毛玻璃效果重构**：将毛玻璃效果和自定义壁纸功能移至高级设置，默认关闭，避免性能影响
- **捐赠页面增强**：重新设计捐赠界面，提供更好的视觉体验和支持选项

### 技术架构升级
- **GitHub Actions 增强**：优化构建流程，解决依赖冲突问题，提高自动化构建稳定性
- **主题系统完善**：深度优化深色模式下的UI显示效果

## 🐛 Bug 修复 (Bug Fixes)

### 文件管理相关
- ✅ **中文文件名上传修复**：解决中文名称文件上传时文件名转义导致的显示错误
- ✅ **大文件上传支持**：修复超过500MB文件无法上传的问题
- ✅ **深色模式UI优化**：
  - 修复新建文件夹输入框文字在深色模式下不可见的问题
  - 优化动态首页标题文字颜色
  - 统一传输列表页面对话框文字主题颜色
  - 修正文件管理页面操作导入问题

### 用户认证与权限
- ✅ **登录验证优化**：统一处理账号密码错误和未加入小组的情况
- ✅ **登录过期检测**：增强登录状态验证机制

### 主题与界面
- ✅ **首页标签页优化**：修复标题文字的主题颜色问题
- ✅ **动态加载组件**：修正加载提示文字的显示样式
- ✅ **捐赠页面配色**：优化捐赠页面的整体色彩搭配

## 🔧 技术改进 (Technical Improvements)

### 性能优化

### 代码质量

- **网络请求增强**：强化网络拦截器和错误处理机制
